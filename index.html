    Touches du clavier

    Cliquez sur une touche, puis tapez la combinaison voulue. Échap annule, Retour arrière retire la touche.

    Les touches ne marchent que lorsque le curseur est dans le widget ; le navigateur garde pour lui Ctrl+N, Ctrl+T et Ctrl+W. Elles sont propres à ce navigateur, comme la langue et le thème.

    Abréviations

      Aucune abréviation pour l'instant.

      Chaque personne a les siennes, enregistrées dans le document (table Publipostage_Abreviations).

      Marges de page (mm) - propres à ce modèle, appliquées à l'aperçu et aux exports PDF/DOCX.

      Réglages propres à cette vue. Pour les appliquer à tout le monde, enregistrez ensuite la vue dans Grist (bouton Enregistrer en haut du widget).

      Modèle selon la ligne

      Ouvre tout seul le bon modèle selon la ligne sélectionnée dans la table de la page, en édition comme en lecture. Les règles se lisent dans l'ordre : la première qui correspond choisit le modèle.

      Vous êtes en lecture seule : ce réglage est verrouillé.

      Un export en lot garde le modèle ouvert pour toutes les lignes exportées.

      Modèle par défaut de cette vue

      Le modèle qui s'ouvre chaque fois que l'on arrive dans cette vue. Sans choix, c'est le modèle par défaut du document (★) qui s'ouvre.

      Vous êtes en lecture seule : ce réglage est verrouillé.

      Droits par personne, lus dans une table du document : une ligne par personne, repérée par son email Grist, et une case à cocher par droit.

      Elles ouvrent sur le document seul, sans la barre d'outils ; le bouton rond du coin haut droit ou Échap leur rend la barre (Commenter, Exporter selon leurs droits). Choisissez d'abord la colonne « Lecture seule ».

      Vous êtes en lecture seule : ce réglage est verrouillé.

      Pour l'appliquer à tout le monde, enregistrez ensuite la vue dans Grist (bouton Enregistrer en haut du widget). Une personne absente de la table garde tous les droits.

      Simple verrou d'interface : seules les règles d'accès de Grist protègent vraiment les modèles et les données.
