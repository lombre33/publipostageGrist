# Code de conduite

*🇬🇧 An English version of this document is available [below](#code-of-conduct).*

## Notre engagement

Nous voulons que ce projet reste un espace accueillant et respectueux pour toutes les personnes qui y
participent, quels que soient leur âge, leur handicap, leur origine, leur genre ou leur identité, leur
orientation, leur expérience, leur nationalité, leur apparence, leur religion ou leurs convictions.

## Ce que nous attendons

- Être respectueux et bienveillant, y compris quand on n'est pas d'accord.
- Critiquer les idées et le code, jamais les personnes.
- Accepter une critique constructive de bonne grâce, et la faire de même.
- Rester patient : le projet est maintenu par une petite équipe, et chacun débute un jour.
- Mettre en avant ce qui sert la communauté, pas seulement soi-même.

## Ce qui n'est pas acceptable

- Le harcèlement, les insultes, les moqueries, les attaques personnelles, les menaces.
- Les propos ou les images discriminatoires ou sexualisés, et l'attention non désirée.
- La publication d'informations privées sans accord, y compris des données personnelles de tiers dans
  un document d'exemple ou une capture d'écran.
- Le pourriel, la publicité sans rapport avec le projet, les messages répétés pour faire pression.
- Tout comportement qui serait déplacé dans un cadre professionnel.

## Portée

Ce code s'applique à tous les espaces du projet (issues, pull requests, discussions, commentaires de
code) et aux situations où une personne représente le projet en public.

## Application

Les mainteneurs peuvent modifier, masquer ou supprimer un commentaire, une issue ou une pull request qui
ne respecte pas ce code, avertir la personne, puis la bloquer temporairement ou définitivement si cela
ne suffit pas. Ils expliquent leur décision quand c'est possible et traitent les signalements avec
discrétion.

## Signaler un comportement

Écrivez aux mainteneurs en privé : utilisez le signalement privé de GitHub décrit dans
[SECURITY.md](SECURITY.md) en indiquant « Code de conduite » dans le titre, ou envoyez un message privé
à l'un d'eux. Ne le faites pas dans un espace public.

# Code of conduct

*🇫🇷 Une version française de ce document est disponible [en haut de cette page](#code-de-conduite).*

## Our pledge

We want this project to remain a welcoming and respectful space for everyone who takes part, whatever
their age, disability, background, gender or identity, orientation, experience, nationality,
appearance, religion or beliefs.

## What we expect

- Be respectful and kind, including when you disagree.
- Criticize ideas and code, never people.
- Take constructive criticism in good part, and give it the same way.
- Be patient: the project is maintained by a small team, and everyone starts somewhere.
- Favor what serves the community, not only yourself.

## What is not acceptable

- Harassment, insults, mockery, personal attacks, threats.
- Discriminatory or sexualized remarks or images, and unwanted attention.
- Publishing private information without consent, including third parties' personal data in a sample
  document or a screenshot.
- Spam, advertising unrelated to the project, repeated messages to pressure someone.
- Any behavior that would be out of place in a professional setting.

## Scope

This code applies to every project space (issues, pull requests, discussions, code comments) and to
situations where a person represents the project in public.

## Enforcement

Maintainers may edit, hide or delete a comment, issue or pull request that doesn't follow this code,
warn the person, then block them temporarily or permanently if that isn't enough. They explain their
decision when they can and handle reports discreetly.

## Reporting a behavior

Write to the maintainers privately: use GitHub's private reporting described in
[SECURITY.md](SECURITY.md), putting "Code of conduct" in the title, or send a private message to one of
them. Please don't do it in a public space.
